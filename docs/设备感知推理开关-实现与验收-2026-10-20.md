## 2. 本机标定与自动采用

[入库工具](../scripts/inference_switch_bench.py)仅在显式执行时标定，选择记录不运行benchmark。工具顺序加载相同工件，真实greedy反馈生成；baseline与candidate必须所有输出token一致、logits有限、至少32个生成token、1次warmup与3次测量。按中位decode吞吐提升至少3%、prefill不低于基线98%判定；KV量化保留显式容量选项。

默认只输出报告，指定`--calibration-out`且结果过门后原子发布。记录默认位置为`STATE_DIR/inference-calibration.json`，`QLH_INFER_CALIBRATION_PATH`可指定隔离记录。记录匹配模型、构建、主机、实际执行设备和加载参数；更换其中任一身份重新核准。binding记录仅供绑定整模消费，server按自身可验证证据消费；特殊RPC／多模态／draft／冻结层段分别保留各自合同。

示例（模型路径替换为实际本机工件）：

```powershell
python scripts/inference_switch_bench.py --model <model.gguf> --threads 4,8 --flash-attn off,on --prompt <prompt> --gen 64 --samples 3 --warmup 1 --json-out <report.json> --calibration-out <state/inference-calibration.json>
```

binding生产入口使用`chat_format="chatml"`时，标定增加`--chat-format chatml`，构造参数与身份记录同步匹配。

标准llama-server未提供逐token完整raw logits；`_server_once`具名拒绝这类有限性证据不足的记录。server采用门须先有相同构建的完整数值观察能力。生成少于32个token、输出分叉或缺少完整有限值证据时保留失败报告，不发布。历史吞吐数据仅作为[原构建实测](设备感知推理开关实测-2026-10-15.md)读取。

## 3. KV与上下文

[inference_context.context_budget_from_gguf](../src/inference_context.py)只读有界header／tensor目录，独立计算实际K/V维度、类型、注意力层及hybrid recurrent常驻状态。标量interval裁层须符合原生本地层型与切点对齐；明确的逐层数组按数组计账，缺信息具名回退。

CPU预算取当前available RAM的1/8；CUDA只消费同设备、30秒内且具有可靠来源的显存样本，外部样本校验UUID。已加载torch CUDA owner可提供全卡global／torch free最小预算；缺可信GPU样本保留原上限。关闭KV offload时按CPU域估算；RPC、混合GPU及embedding的未知cache布局具名回退。总槽位向下按`sequence_count × 256`对齐，逐序列检查最小context。估算仅约束自动上下文，显式n_ctx及部署load_spec仍为权威。

`ModelHost`和`ModelManager`正常本地入口以tier为上限交给预算函数；context预算、采用值与回退原因随此次加载保留。

## 4. 验证记录

证据根：`build/device-aware-infer-20261020/`。原版四个参数接线失败前例保留于`loader-red-original-r1.json`；各执行结果按原始JSON／JUnit分别读取，重叠用例不加总。

### 4.1 自动化与原生加载

| 证据 | 口径与结果 |

| `loader-red-original-r1.json` | 原版4个红例：环境线程被默认值遮挡、Flash off未传达、字符串KV触发ctypes错误、冲突异常被吞 |
| `final-integration-r3.xml` | 最终串行集成回归：629通过、10项按环境条件跳过；覆盖开关／标定／header预算、loader、ModelHost／ModelManager、TUI API、冻结层段与子进程 |
| `final-loader-api-r2.xml` | 127通过；标定记录→真实选择器→loader参数→当前模型API投影，含采用、关闭、显式覆盖、损坏及context失配。此正例使用可控吞吐证据，验证接线 |
| `native-owner-smoke-r2.json` | Qwen3-0.6B Q8_0，CPU binding 0.3.35，单序列、n_ctx=512；基线、显式off／3线程、q8 KV联动Flash、损坏记录回退4组均完成32个自由greedy token，完整logits有限、API投影一致且卸载清状态 |
