来源：`local_docs/evidence/relay-xframe/CORE-RELAY-XFRAME-02-real-relay-2026-09-18.json`、`...-real-relay-v2-...json`、`...-upstream-profile-...json`
条件：Qwen2.5-0.5B（12 层）；上游 `load_layer_range`+`forward_layers`（CUDA, f16）；下游 llama.cpp 裁层 GGUF（CPU）；gen=32；**同一进程、同一模型、同一 prompt、同一设备**下依次测量。

| 变体 | forward ms/步 | forward ms/层 | 下游 ms/步 |
|---|---:|---:|---:|
| A forward-only | 12.089 | 1.0075 | 0.0 |
| B +convert | 12.277 | 1.0231 | 0.0 |
| C +downstream（真接力） | 30.003 | 2.5003 | 28.656 |
| D +whole-model | 30.798 | 2.5665 | 24.856 |

| 差分（ms/步） | 值 |
|---|---:|
| B−A（张量转换） | +0.188 |

### B8. B13：hybrid（Qwen3.5）的层流水线（**已完成**）

来源：`local_docs/evidence/relay-xframe/CORE-RELAY-XFRAME-02-b13-hybrid-pipeline-2026-09-18.json`
条件：**同进程**；Qwen3.5-2B（hybrid，24 层）；**split=12**（上游 0-11 含 embed、下游 12-23 含末节点口径）；
prefill=16、gen=32、**repeats=3**；CUDA f16；**compile 关闭**（比语义不比性能）。

| 项 | 数字 |
|---|---:|
| 上游 0-11 ms/步 | **25.251 ± 0.232** |
| 下游 12-23 ms/步 | **23.960 ± 0.602** |
| 合计 ms/步 | **49.211** |
| **逐 token argmax vs 单段 0-24** | **完全一致**（33 个 token，首个差异 = None） |

- **结论：段间不需要传任何 cache。** 契约本就如此 —— `past_key_values` 的索引对应「**本节点本地层**」
  （`src/model_module.py:3039`）；`_kv_cache` 按 `task_id` 存「本节点层范围的 KV」（`src/scheduler.py:1090`）。
- hybrid 的 `linear_attention` 层不写 KV、用 conv/recurrent state，**只依赖本层输入序列** ⇒ 只要
  **prefill 阶段上游传完整序列的 hidden**，下游就能从 token 0 正确累积 ⇒ **不引入额外跨节点状态传输**。
- ⚠️ **对照口径**：单段 vs 两段是「同进程、同脚本、同输入条件」；单段口径 A3 已证与 transformers 整模 argmax 一致。
  ⚠️ **耗时只在两段侧测量**（8GB 卡放不下单段 4GB + 两段 4GB 同时驻留 ⇒ 单段跑完先释放），参照侧仅用于 token 对照。
- ⚠️ **副产品（主仓缺陷）**：tied 模型（Qwen3.5）**无法做末节点**（`has_lm_head=True` 抛
  `qwen2 分层权重不完整: lm_head.weight`，`src/model_module.py:1698`）⇒ 见 `TODO-B16`。本实验因此把下游
  也按 `has_lm_head=False` 加载，再补 `norm` + **上游那份 tied embed 权重**的 matmul（同 A3 口径）。

### D3. compile 非 bit-exact = f16 的 1 ULP

来源：`local_docs/evidence/relay-xframe/CORE-RELAY-XFRAME-02-compile-numerics-2026-09-18.json`
条件：qwen2.5-0.5b, **12 层, gen=141, prefill=64, f16, sdpa**（A eager 11.37 ms/step）。

| 档 | ms/step | 相对 A | hidden max\|diff\| |
|---|---:|---:|---:|
| A eager | 11.37 | 1.0× | — |
| B compile(default) | 6.584 | 1.727× | **0.015625** |
| C +emulate_precision_casts | 6.121 | 1.858× | 0.015625 |
| D +deterministic | 6.68 | 1.702× | 0.015625 |
| E +no_epilogue_fusion | 5.736 | 1.982× | 0.015625 |
| F +no_split_reductions | 5.774 | 1.969× | 0.015625 |

- 结论：差异 = **f16 的 1 ULP**（`0.015625 = 2^-6`，恰为 f16 在 `|x| ∈ [16,32)` 的 ULP）；逐项排除后**唯一剩余来源 = attention 实现通路**（`fuse_attention` 把 bmm+softmax 融回 aten SDPA）。
- **表述纪律**：上游 issue 原话指出 compile 版本对照 **float64** 基线时 **rtol 更好** ⇒ **不得表述为「compile 更差」**；正确说法是「**与 eager 非逐位一致**」。
- ⚠️ 另一值 `0.078125` 来自 P9 **整模** compile（gen=64）⇒ **不同轮次/序列，不可混用**。
