## 1. 目标终端矩阵（定死三者）

| 代号 | 终端 | 角色 | 环境特征 |
| --- | --- | --- | --- |
| **T1** | **Windows Terminal** | Windows 侧主终端（含 conhost 老版=降级档） | ConPTY、VT 支持（需启用）、`WT_SESSION` 可检测、truecolor |
| **T2** | **Termux**（Android） | 移动端 TUI 载体（L 档引擎可在 Termux 跑） | POSIX termios、`TERMUX_VERSION`/`PREFIX` 可检测、`xterm-256color`、**手机窄屏**、软键盘 |
| **T3** | Linux 终端（xterm 系/gnome/kitty…，WSL 可测） | 桌面 Linux 与验证环境 | termios、256 色~truecolor |

## 2. 基调原则（八条）

1. **零第三方依赖（硬）**：TUI 仅用 Python 标准库——Termux 上装依赖困难，且与边缘基线（L 档无 torch）一致。**不引入 Textual 等重框架**（现有 `tui_chat` 已是 715 行零依赖范本）。
2. **能力检测 + 分级降级**：启动时按序检测——① VT 可用性（Win：`ENABLE_VIRTUAL_TERMINAL_PROCESSING` 启用成功；POSIX：`sys.stdin.isatty()`）→ ② 环境标识（`WT_SESSION`→T1；`TERMUX_VERSION`/`PREFIX`→T2；`TERM` 含 `256color`）→ ③ 色彩档（truecolor：`COLORTERM=truecolor|24bit`；否则 **256 色**；再否则 16 色）→ ④ 尺寸。**任一环失败降级**（现有 `TermNotCapable` 模式扩展为分级：truecolor→256→16→纯文本编号菜单）。
3. **VT 子集取交集**：只用 xterm-256color 兼容序列（SGR 颜色/光标/清屏/折行）；truecolor 仅当 `COLORTERM` 明确声明时启用；**不使用任何厂商扩展序列**。
4. **键盘模型双轨 + 手机容错**：Windows=`msvcrt`；POSIX=termios/tty+`select`（现有实现 ✓）。**Termux 特例**：软键盘方向键/退格/回车序列存在差异 → 键位映射做容错表（多种序列映射到同一语义键）；**命令输入以 ASCII 为准**（中文内容经输入法/粘贴/参数传入，不依赖 IME 逐键交互）。
5. **窄屏响应式（双布局）**：宽（≥80 列）完整布局；**窄（<80 列，手机常态）**单列布局——单行消息截断（显示宽度算）+ 状态行压缩 + 菜单分页。T3/T1 默认宽，T2 默认窄（可 `--layout wide|narrow|auto` 覆盖）。
6. **宽字符宽度一致**：中文/emoji 按**显示宽度**（自实现 wcwidth：CJK 宽=2、组合字符=0）做对齐/截断/换行——三终端下对齐一致（Termux 与 WT 的渲染都要预期一致）。
7. **信号与生命周期**：`SIGINT`（Ctrl-C 中断生成/退出）、`SIGWINCH`（尺寸变化重排）、Termux 前后台切换（进程挂起恢复）均不崩溃；退出恢复终端态（termios 恢复 / Win 还原模式）。
8. **无色彩可用性**：管道/无 VT 环境（如 CI 日志、老 conhost）自动降级纯文本；**所有 TUI 功能在无色彩下仍可用**（颜色只是增强）。

## 3. 验收门（三终端冒烟矩阵）

| 项 | T1 Windows Terminal | T2 Termux（安卓） | T3 Linux/WSL |
| --- | --- | --- | --- |
| 渲染（边框/颜色/清屏） | 本机可测 ✓ | 真机待设备 ⏳ | WSL 可测 ✓ |
| 输入（方向/退格/回车/组合键） | 本机 ✓ | 真机 ⏳（软键盘容错表） | WSL ✓ |
| 流式输出（SSE 逐段） | 本机 ✓ | 真机 ⏳ | WSL ✓ |
| 中文宽字符对齐 | 本机 ✓ | 真机 ⏳ | WSL ✓ |
| 窄屏布局（<80 列） | 窗口缩窄可测 ✓ | 真机 ⏳（机身常态） | 可测 ✓ |
| 中断/退出/恢复终端态 | 本机 ✓ | 真机 ⏳ | WSL ✓ |
| 无色彩降级 | 管道可测 ✓ | — | 管道可测 ✓ |
| **引擎连通**（`qlh chat` 对话） | 本机 ✓（llama.cpp 直连） | 真机 ⏳（Termux 版 llama.cpp） | WSL ✓ |

> **设备依赖**：T2 的实机验收需要安卓设备（Termux 安装 Python + llama.cpp 编译；从节点 Surface 为 Windows 不覆盖 T2）。

## 4. 现状与差距（2026-09-14 核对）

**已备**（`tui_admin.py` 能力层）：VT 启用（Win ctypes）· 双平台按键（msvcrt/termios+select）· `TermNotCapable` 降级异常 · `tui_chat` 零第三方（715 行）。
**待补（按基调）**：① 环境检测（`WT_SESSION`/`TERMUX_VERSION`/`COLORTERM`）；② 色彩档分级（256/truecolor）；③ 窄屏双布局；④ wcwidth 显示宽度对齐；⑤ `SIGWINCH` 重排；⑥ Termux 键位容错表；⑦ 三终端冒烟脚本（可自动化部分：管道/窄宽模拟）。
