# 静态主节点部署与认证退役决策

> 状态：**现行**
> 裁定日期：2026-10-27
> 更新日期：2026-10-28
> 适用范围：主仓支持的节点角色、主节点故障边界、账户功能退役及集群连接安全边界。

## 决策

集群采用静态角色。部署时恰好一台节点显式配置 `QLH_NODE_ROLE=master`；其余节点配置为 `client` 或不设置角色，未指定角色默认按 client 处理。旧配置中持久化的 `role=auto` 安全迁移为 `client`，不会因迁移而取得主节点身份。

Client 可以发现并重新连接到已配置的静态 master，但绝不自行晋升。Master 故障时不自动接管；集群控制与依赖 master 的请求保持不可用，直到原 master 恢复或运维在确认旧 master 已停止后人工完成角色迁移。自动选举、quorum voter、备用主节点、角色转让和转让审查不属于支持的产品运行时。

人类账户、登录/注销、用户管理和 TOTP 审批功能退役。节点间身份与连接安全仍由 `cluster_secret`、bootstrap 凭据交换、TCP HMAC 注册和可信来源检查保护；本决策不放宽这些机器身份边界。节点继续保留本地用户偏好与聊天会话，它们不依赖集群账户。

## Windows PowerShell 配置

以下配置写入当前 Windows 用户环境，并同步到当前 PowerShell 会话。修改后重启 QLH 进程，使启动时读取新配置。

在唯一的 master 主机执行：

```powershell
[Environment]::SetEnvironmentVariable('QLH_NODE_ROLE', 'master', 'User')
$env:QLH_NODE_ROLE = 'master'
```

在其他 Windows 节点执行，将示例地址替换为 master 的可达主机地址。`QLH_CLIENT_MASTER_PORT` 是 worker TCP 端口（默认 `8888`），`QLH_MASTER_API_PORT` 是 HTTP API 端口（默认 `8000`）；若部署改过端口，填写实际值：

```powershell
[Environment]::SetEnvironmentVariable('QLH_NODE_ROLE', 'client', 'User')
[Environment]::SetEnvironmentVariable('QLH_CLIENT_MASTER_HOST', '100.90.76.108', 'User')
[Environment]::SetEnvironmentVariable('QLH_CLIENT_MASTER_PORT', '8888', 'User')
[Environment]::SetEnvironmentVariable('QLH_MASTER_API_HOST', '100.90.76.108', 'User')
[Environment]::SetEnvironmentVariable('QLH_MASTER_API_PORT', '8000', 'User')
$env:QLH_NODE_ROLE = 'client'
$env:QLH_CLIENT_MASTER_HOST = '100.90.76.108'
$env:QLH_CLIENT_MASTER_PORT = '8888'
$env:QLH_MASTER_API_HOST = '100.90.76.108'
$env:QLH_MASTER_API_PORT = '8000'
```

Client 可省略 `QLH_NODE_ROLE`，默认即为 client；显式写出可让部署意图更清楚。其他平台在其受支持的进程环境或节点连接设置中采用同一角色与 master 地址。不要在多个节点配置 `master`。替换 master 时，先停止旧 master，再调整角色并启动新节点。

配置后从该 PowerShell 会话运行 `koakuma`（或 `qlh`）；本段只设置角色与连接地址，不更换 `cluster_secret`，不删除本地偏好或聊天会话。

## 部署边界

- 节点发现、静态地址连接、断线重连和 worker 注册仍可用；连接或发现不会改变节点角色。
- 本地用户偏好及聊天会话继续保留在各自节点。
- 不再部署 `QLH_NODE_ROLE=auto`。旧环境值或持久化 auto 角色安全按 client 处理，不触发选举或升主；部署应显式指定唯一 master，并清理旧 HA/voter 配置。
- 本文取代早期自动选主、quorum、备用主节点、角色转让/审查的方案与部署指引。既有设计、演练和验收材料只作为历史证据，不作为当前待办或运行说明。
