## 1. 客户端观测与事实归属

[contracts/snapshots.py](../src/qlh_core/contracts/snapshots.py)的`envelope/Reason`定义schema_version=2，revision、identity、observed_at、validity及带domain／code／source／retryability／details／cause的结构化真因。跨owner复合查询由[ClientSnapshots.current](../src/qlh_core/bootstrap/client_snapshots.py)在有限重试内重验版本；竞争返回pending。查询消费已发布状态，加载与恢复由命令入口触发。

[ModelIntentCoordinator.current/get](../src/model_intent.py)读取`DeploymentService`，移除了旧intent.json读写兜底；ready同时接受`ExecutionApplication.freeze`的当前准入。[/api/client/state与events](../src/api/routes_client_state.py)共享同一投影；变更通过SSE发送，无变更发送keepalive。[/api/models/current](../src/api/routes_models.py)在runtime publication锁内投影原生状态及版本，摘要沿用已发布描述符。

[RequestService.recent/queue_snapshot](../src/qlh_core/execution/requests.py)分别返回有界历史和FIFO快照；逻辑terminal与物理execution_state独立展示。历史查询可读取耐久记录，且不启动执行线程或恢复。会话选择由[ConversationContextService](../src/chat_context.py)按client_id保存，HTTP与SSE共享客户端身份；线性请求使用明确session和revision，成功turn按CAS提交。隐式会话ID使用客户端标识的稳定摘要，符合SQLite session约束并隔离不同客户端。

[ParticipationService.change](../src/qlh_core/control/participation.py)先持久化desired，再公布joining／leaving，原生清理完成后进入stable；失败保留具名真因。[AppRuntime](../src/qlh_core/bootstrap/runtime.py)通过同一IdentityStore写节点配置、凭据与参与意图，重启后恢复显式local选择。

TUI的[ApiClient.accept_snapshot](../src/tui_api.py)和`model_intent_ready`、Web的`data/snapshots.ts`、Android的`ClientSnapshotCursor`与`ModelIntentController`核对版本、boot、revision、有限observed_at及validity。旧revision、旧boot观测与pending关闭聊天准入。HTTP和SSE错误携带同一原因链；用户选模、切换会话或模式后，旧异步结果由请求代际围栏拒绝。Android Room用户数据和系统SAF授权继续由本地owner维护。

## 3. 显式离线迁移

`qlh migrate-state --source PATH --target PATH --backup PATH --dry-run`调用[state_migration.inspect](../src/qlh_core/adapters/state_migration.py)。预检只读检查独立路径、版本、SQLite完整性及hash chain、凭据AES-GCM、非空WAL／journal、链接与空间；未知schema、损坏凭据、缺失日志或未辨认运行态在创建备份前具名拒绝。

去掉`--dry-run`后先校验复制到独立备份，再生成暂存目标，重验source fingerprint，最后原子rename。节点ID、凭据epoch、会话、偏好、工件引用及工作台文件保留；只重映射明确的内部state／数据库／凭据路径。已识别运行态根下的KV与readiness留在备份，用户`workbench/operations`保留。只对含控制／请求表的数据库执行失效处理，其他用户SQLite保持原字节。

新控制态设置迁移哨兵boot，清空active deployment及选择，撤销prepare／commit命令并失效旧deployment；旧未完成请求结束为`request_state_migrated`，清理债务逐项保留并报告reconciliation_required。报告仅含路径、摘要及状态。SAF URI引用保留，系统授权由Android重新观测。重复执行以source fingerprint核对既有报告。
